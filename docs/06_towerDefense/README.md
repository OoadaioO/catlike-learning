# Tower Defense 塔防游戏代码框架结构

## 项目概述

Tower Defense 是一个完整的塔防游戏实现，展示了 Unity 中游戏系统架构、敌人 AI、塔防机制、动画系统等核心功能的实现。项目采用组件化架构，遵循单一职责原则，各系统之间通过接口和事件进行解耦。

## 核心架构

### 1. 游戏管理系统

**Game.cs** - 游戏主控制器
- 负责游戏状态管理（暂停、速度控制）
- 管理玩家生命值和游戏场景
- 协调各子系统之间的交互
- 处理用户输入和射线检测

**GameScenario.cs** - 游戏场景配置
- 定义波次配置和敌人生成序列
- 管理游戏进度和难度曲线

**GameBoard.cs** - 游戏地图系统
- 管理瓷砖网格和路径finding
- 处理瓷砖内容（塔、墙、出生点等）的放置
- 提供寻路功能和瓷砖状态查询

### 2. 敌人系统

**Enemy.cs** - 敌人基类
- 敌人移动逻辑（沿路径移动）
- 生命值管理和伤害计算
- 目标点管理和碰撞检测
- 动画状态同步

**EnemyFactory.cs** - 敌人工厂
- 对象池模式实现敌人创建和回收
- 管理不同敌人类型的实例化

**EnemyCollection.cs** - 敌人集合管理
- 批量管理所有活跃敌人
- 提供敌人查询和统计功能

**EnemyWave.cs** - 敌人波次管理
- 定义波次的敌人配置和生成时机

**EnemySpawnSequence.cs** - 敌人生成序列
- 控制单个敌人的生成时间和类型

**EnemyType.cs** - 敌人类型枚举
- 定义不同类型的敌人（普通、快速、装甲等）

### 3. 塔防系统

**Tower.cs** - 塔基类（抽象）
- 目标获取和跟踪逻辑
- 射程检测和范围可视化
- 提供塔类型的抽象定义

**LaserTower.cs** - 激光塔
- 持续伤害机制
- 光束渲染和效果

**MortarTower.cs** - 迫击炮塔
- 范围爆炸伤害
- 弹道计算和炮弹发射

**Shell.cs** - 炮弹
- 弹道轨迹和爆炸效果
- 伤害范围计算

### 4. 瓷砖系统

**GameTile.cs** - 游戏瓷砖
- 瓷砖类型和状态管理
- 相邻瓷砖连接和路径计算
- 内容（塔、墙等）的放置和管理

**GameTileContent.cs** - 瓷砖内容基类
- 定义可放置在瓷砖上的对象基类
- 提供内容类型和状态管理

**GameTileContentFactory.cs** - 瓷砖内容工厂
- 管理所有瓷砖内容的创建
- 对象池模式实现内容复用

**GameTileContentType.cs** - 瓷砖内容类型枚举
- 定义不同类型的瓷砖内容

### 5. 动画系统

**EnemyAnimator.cs** - 敌人动画控制器
- 管理敌人动画状态机
- 处理移动、受伤、死亡动画切换
- 动画事件处理

**EnemyAnimationConfig.cs** - 敌人动画配置
- 定义不同敌人的动画参数
- 动画剪辑和混合树配置

### 6. 目标系统

**TargetPoint.cs** - 目标点管理
- 敌人目标点的碰撞检测
- 目标点缓存和随机选择
- 射程验证和目标跟踪

### 7. 工具类

**Direction.cs** - 方向枚举
- 定义六个移动方向（六边形网格）
- 方向转换和计算方法

**FloatRange.cs** - 浮点范围
- 定义最小值和最大值范围
- 随机值生成和范围检测

**FloatRangeSliderAttribute.cs** - 范围滑块属性
- 自定义属性绘制器，提供Inspector中的范围滑块

**WarEntity.cs** - 战争实体基类
- 定义敌人、炮弹等实体的基础功能
- 提供回收接口

**WarFactory.cs** - 战争工厂基类
- 提供通用的对象池实现
- 管理游戏实体的创建和回收

**GameBehavior.cs** - 游戏行为基类
- 提供游戏对象的回收机制
- 定义游戏行为的基础接口

**GameBehaviorCollection.cs** - 游戏行为集合
- 批量管理游戏行为对象
- 提供更新和回收功能

**GameObjectFactory.cs** - 游戏对象工厂
- 提供通用的GameObject创建和回收
- 管理预制体实例化

### 8. 特效系统

**Explosion.cs** - 爆炸效果
- 爆炸粒子效果控制
- 爆炸范围可视化

## 设计模式应用

1. **工厂模式**: EnemyFactory, GameTileContentFactory, WarFactory
2. **对象池模式**: 所有工厂类实现对象复用
3. **状态模式**: EnemyAnimator 管理动画状态
4. **模板方法模式**: Tower 抽象类定义塔的行为框架
5. **组件模式**: Unity 的组件化架构
6. **观察者模式**: 通过 Unity 事件系统实现解耦

## 系统交互流程

1. **游戏启动**: Game.Awake() → 初始化地图、工厂、场景
2. **敌人生成**: GameScenario → EnemyWave → EnemySpawnSequence → EnemyFactory
3. **敌人移动**: Enemy → GameTile → 路径finding → 目标点检测
4. **塔攻击**: Tower → TargetPoint → 敌人检测 → 伤害计算
5. **动画同步**: Enemy → EnemyAnimator → 状态切换 → 视觉表现

## 性能优化

- 对象池模式减少GC压力
- 集合类批量更新减少组件查询
- 缓存机制避免重复计算
- 射线检测优化和分层管理
- 动画状态机高效切换

## 扩展性设计

- 抽象基类提供扩展点
- 工厂模式支持新类型添加
- 配置驱动设计便于平衡调整
- 组件化架构支持功能组合
- 事件系统支持模块间通信
